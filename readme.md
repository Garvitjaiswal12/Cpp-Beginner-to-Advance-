# 🚀 C++ Tutorial

Welcome to the **C++ Tutorial** repository! 👋

This repository is designed to help beginners learn **C++ programming from the basics to advanced concepts** through simple explanations, examples, and practice programs.

Whether you're completely new to programming or want to strengthen your C++ fundamentals, this repository can serve as your learning companion.

## ▶️ How to Run the Programs

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/your-repository.git
```

### 2. Navigate to the Repository

```bash
cd C++-Tutorial
```

### 3. Compile a C++ Program

Using **g++**:

```bash
g++ program.cpp -o program
```

### 4. Run the Program

**Windows:**

```bash
program.exe
```

**Linux/macOS:**

```bash
./program
```
